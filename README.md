# 東京都の小規模事業者向け 助成金・補助金サーベイ（2026年9月1日時点）

東京都内の小規模事業者（サービス業）が申請しうる助成金・補助金を、**28の切り口で並列に全件スキャン**した結果です。すべて公式サイト・公募要領PDFの一次情報にあたり、出典URLを付けています。

> **なぜ公開しているか**
> 補助金情報は、アグリゲーターサイトの日付が古かったり、実施主体の公式サイト同士で日程が食い違っていたりします。そこで何度も足をすくわれたので、**どこに落とし穴があるかを含めて**共有します。制度そのものより「調べ方の失敗パターン」の方が役に立つかもしれません。
>
> 特定企業の申請状況・経営判断は含みません。制度情報のみです。

**確認日：2026年9月1日**／情報は変わります。申請前に必ず出典URLで再確認してください。

## 1. まず知っておくべき5つの落とし穴

### 落とし穴① 同じ組織の中でも日程が食い違う

**新事業進出・ものづくり商業サービス補助金 第1回**は、2026年7月17日にスケジュールが1か月後ろ倒しに変更されました。

| | 旧 | 現行 |
|---|---|---|
| 申請受付開始 | 8月31日 | **9月30日（水）** |
| 応募締切 | 9月30日 18:00 | **10月30日（金）18:00 厳守** |
| 採択発表 | 令和8年12月 | **令和9年1月** |

問題は、**中小企業庁の告知ページと中小機構のニュースリリースが旧日程のまま残っている**ことです。変更後の日程は公募スケジュールページにしか反映されていません。

**教訓：一次情報の中にも新旧がある。**

| 優先度 | 文書の種類 | 性質 |
|---|---|---|
| 高 | **公募スケジュールページ・公募要領の最新版** | 更新され続ける |
| 中 | 制度トップページ／お知らせ一覧 | 更新されることもある |
| 低 | **ニュースリリース・プレスリリース** | **発行時点で凍結される** |
| 使わない | アグリゲーターサイト・解説記事 | 出典として使えない |

スケジュールページのHTMLに取り消し線（`<s>`タグ）が入っていることがあります。**旧日程が打ち消され新日程が併記されている**サインです。

**⚠️ ただし取り消し線が入るとは限りません。**2026年9月1日時点の同スケジュールページでは、**取り消し線なしで旧日程と新日程が同じセルに並記**されています（申請受付「令和8年8月31日」「令和8年9月30日」／応募締切「9月30日18:00厳守」「10月30日18:00厳守」）。変更・延長を示す注記もなく、制度トップのお知らせでも解決できません。**ページ単体では判別不能**という状態が実在します。こうなったら、公募要領PDFの最新版・改訂履歴まで降りるしかありません。

### 落とし穴② 「都の助成金＝中小企業振興公社」ではない

東京都の制度には**少なくとも3系統**あります。公社の一覧をどれだけ丁寧に見ても、他の系統は1件も載りません。

| 実施主体 | 扱う分野 |
|---|---|
| **東京都中小企業振興公社** | 設備投資・製品開発・販路開拓・DX |
| **東京しごと財団** | 雇用・働き方・テレワーク・人材確保・育成 |
| **東京都産業労働局 直轄・委託** | デジタル化支援、価格転嫁支援など |

テレワークトータルサポート助成金（上限150万円・助成率2/3）は**しごと財団**の制度で、公社の一覧には存在しません。

### 落とし穴③ 金額が「サイトに書いていない」ことがある

しごと財団の助成金は、**HTMLページに金額が書かれておらず、募集要項PDFにしか載っていない**ものが複数あります。ページだけ見て「金額不明」と判断すると取り逃します。

また、似た名前の別制度が並存していることもあります。東京都の「**DX推進助成金**」（上限3,000万円）と「**DX推進トータルサポート事業**」（上限1,500万円）は別物です。金額の食い違いに見えて、実は違う制度を比べていた、ということが起きます。

### 落とし穴④ 「支給申請期間が開いている」＝「まだ申請できる」ではない

**ABWオフィス促進助成金**（東京しごと財団・上限2,000万円・助成率2/3）は、募集要項にこう書かれています。

> 「２ 申請の受付期間　令和８年６月１日（月）9：00 ～ **令和９年１２月３１日（金）**23：59 まで」

一見、2027年末まで余裕があります。しかし同じPDFの1ページ目にこうあります。

> 「■ABW 導入支援の申込・申込受付期間：令和８年６月１日（月）９：００～**令和８年７月３１日（金）１８：００**まで」
> 「助成金は ABW 導入支援に申込、**支援対象として決定した事業者のみ**申請できます。※支援対象と決定していない事業者からの申請は受付出来かねます。」

**入口（導入支援の申込・募集5社）は7月末で閉じており、後ろの支給申請期間だけが1年半開いている構造**です。同じ形は他にもあります。東京都の**中小企業収益力強化サポート事業**も「助成金のみの申請はできません」と明記され、先に専門家派遣の申込が必要です。

**教訓：締切表の日付だけを見ない。「その日付は入口の締切か、出口の締切か」を必ず確かめる。**

### 落とし穴⑤ 「先に整備すると対象外になる」制度がある

補助金は「先に準備を整えてから申請する」ものだと思っていると、逆をやられます。東京しごと財団の奨励金には、**申請時点で未整備であることが要件**のものがあります。

| 制度 | 順序 | 根拠 |
|---|---|---|
| サテライトオフィス勤務導入奨励金（10万円） | **申請が先 → 整備が後** | 「支給申請日時点で、『サテライトオフィス勤務に関する規定』が**ない**こと」／既に整備されていた場合は「奨励対象外」 |
| ワーケーション勤務導入奨励金（10万円） | **申請が先 → 整備が後** | 「支給申請日時点で、『ワーケーション勤務を可能とする規定』が**ない**ことが支給対象事業者要件」 |
| テレワーク定着強化奨励金（最大40万円） | **取組の実施 → 規定改正 → 申請** | 「Step2で決定（Step4で見直し）した内容について、規定の改正が必要な内容を含む場合は、就業規則・テレワーク規定等を改正し反映してください」 |

**名前が似ていて実施主体も同じなのに、順序が逆です。**先に規則を整えると、前の2つは受給できなくなります。

同種の注意点として、設備投資系の補助金はほぼ例外なく**交付決定前の発注・契約・購入が対象外**です（テレワークトータルサポート助成金は「支給決定日より前の申込・発注・契約・購入は一切対象外」と明記）。**「早く動く」方向を間違えると、どちらの向きでも落ちます。**

## 2. 法人格の壁 ── 一般社団法人・NPOはどこまで使えるか

日本の補助金の多くは、対象を中小企業基本法の「**会社及び個人**」に限定しています。一般社団法人はこの定義に入らず、**規模を問う前に法人格で落ちます**。

| 制度 | 一般社団法人 | 根拠（公募要領の記述） |
|---|---|---|
| 小規模事業者持続化補助金 | **✕** | 「補助対象にならない者」に**一般社団法人、公益社団法人**を明記 |

## 補助金がない分野もある

調べた結果として、**そもそも事業者向けの助成金がほとんど存在しない分野**もありました。たとえば安全教育の実施を請け負う事業では、資金は「自治体の一般財源 → 業務委託・入札」という経路でしか流れておらず、受注者側が使える助成制度は確認できませんでした。

こういう分野では、**補助金を探し続けるより、発注側の予算がどこにいくら付いているかを調べる方が早い**ことがあります。自治体の予算・事業実績は公表資料として手に入ることが多く、営業先の特定にそのまま使えます。

「見つからなかった」ことも調査結果です。無いものを探し続けるコストの方が、たいてい高くつきます。

## 調査方法について

28の切り口（国7・都7・区市3・分野別9・追跡2）に分けた**並列エージェント**で、固定URLリストを全件開いて調査しました。分けた理由は、直列に多数のURLを見ると**後半ほど確認が雑になる**からです。
